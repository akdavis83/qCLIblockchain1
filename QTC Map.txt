16. Phase 6 — Add SHA-256 mining

Only after transactions work.

Your miner should initially be extremely simple:

while true:

    block = get_block_template()

    block.nonce++

    hash =
        SHA256(
            SHA256(
                serialize(block_header)
            )
        )

    if hash < target:
        submit(block)

This is the original Bitcoin-style PoW model you are asking for.

The block header's previous-block hash and Merkle root commit the chain and transaction set, while PoW makes changing historical blocks increasingly costly.
