Day 1–7 should be treated as a foundation sprint, not a BitcoinII port yet. The goal is to finish the week with a small, buildable QTC protocol/CLI that can create a chain, create UTXOs, use SHA-256 PoW, and establish the interface that your existing PQ wallet will eventually use.

Since you're working primarily on Windows/WSL, I'll structure this so you can build it incrementally from the terminal.

6. Define the block

include/block.h

Conceptually:

#pragma once

#include <cstdint>
#include <string>
#include <vector>

namespace qtc {

struct BlockHeader {
    uint32_t version;
    std::string previous_block_hash;
    std::string merkle_root;
    uint64_t timestamp;
    uint32_t difficulty_bits;
    uint64_t nonce;
};

struct Block {
    BlockHeader header;
    std::vector<std::string> transactions;
};

}

This is intentionally simple.

We're not yet trying to reproduce Bitcoin Core's internal serialization architecture.

We're establishing the QTC protocol model.

16. Build a tiny CPU miner

Start with:

Block Header
     ↓
serialize
     ↓
SHA256
     ↓
SHA256
     ↓
compare target
     ↓
valid?

Pseudo-code:

while (true) {

    block.header.nonce++;

    auto hash =
        double_sha256(
            serialize(block.header)
        );

    if (hash <= target) {
        return block;
    }
}
